## Core Principles

- Business value first
- Approved SRS is the source of truth
- RAG retrieves authoritative context
- LLM reasons and generates
- Deterministic code validates and governs
- Agents coordinate; tools act
- Evidence supports conclusions
- Runtime dependencies are explicit
- No fabricated data, IDs, results, or evidence
- No silent baseline changes
- Conflicts become governance findings
- Human approval is preserved
- GREEN / YELLOW / RED governance
- Every result must be traceable

## MVP1 Relationship

MVP1 is frozen and remains untouched.

MVP2 may reuse proven generic foundation components from MVP1,
but MVP2 application-specific artifacts are maintained separately.
