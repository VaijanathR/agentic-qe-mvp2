# 6. Evidence-Based RCA

For every RCA conclusion, record:

1. Failure symptom
2. Observed evidence
3. Relevant logs
4. Relevant screenshots/artifacts
5. Requirement/testcase/data context
6. Historical evidence, if available
7. Agent inference, if any
8. Root-cause hypothesis
9. Confidence
10. Final RCA classification
11. Recommended next action

Clearly distinguish:

**FACT → EVIDENCE → INFERENCE → CONCLUSION**

Do not present inference as fact.

Do not fabricate evidence.

---

# 7. Historical Probability vs Current Evidence

Where historical failure information exists, use it only as supporting evidence.

Current execution evidence takes precedence over historical probability.

For example:

If historically a locator issue occurred frequently, but current evidence clearly demonstrates an environment outage, classify the current failure according to current evidence.

Historical probability MUST NOT override direct current evidence.
